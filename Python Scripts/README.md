# Python Scripts

Miscellaneous Python scripts used for the project.

1. `generate_densities.py` : Given the results.txt file containing the positions for every particle at every frame, condense that information into particle counts across small box-shaped regions for every frame.

2. `timing_plot.py`: Simple matplotlib code for generating a histogram of the time taken for each epxerimental condition (baseline CPU, OpenMP, GPU). Result is `timing_result.png`.
