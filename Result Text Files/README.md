# Result Text Files

## `results.txt`

This file contains the raw output from the simulator, recording the x, y, and z positions of 10,000 particles over 10 frames.

•Each particle’s position is separated by commas.

•Each frame is separated by a newline.

• While the simulation can be run under different conditions (CPU baseline, OpenMP, GPU), all runs produce very similar rsults when using the same random seed.

• Note on numerical differences:

	•	OpenMP uses parallel loops, and floating-point addition is not strictly associative, so small differences can appearcmpared to the serial CPU version.

    •The GPU performs calculations in single-precision (float), which can introduce slight deviations from CPU results.

    •For simplicity, only one results.txt file from the CPU baseline is included.

## `densities.txt`

This file is generated by Python Scripts/generate_densities.py and provides a condensed view of the simulation:

• Instead of individual particle positions, it reports the number of particles in each region of the simulation box.

• The box is divided into 100 regions.

• Each frame’s density data is recorded on a separate line.
